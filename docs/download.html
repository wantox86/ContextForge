📦 Installation

Download the .zip for your Mac architecture above.

Build from source

Prefer to build it yourself?

Full instructions for all platforms. Requires Go 1.22+, Node.js 18+, and Wails v2.

🔧 Prerequisites

ToolVersionInstall
Go1.22+ go.dev/dl
Node.js18+ nodejs.org
Wails CLIv2 go install github.com/wailsapp/wails/v2/cmd/wails@latest
gcc (Linux)latest sudo apt install build-essential
Xcode CLI (macOS)latest xcode-select --install
TDM-GCC (Windows)latest jmeubank.github.io/tdm-gcc

⚒️ Build commands

# 1. Clone
git clone https://github.com/wantox86/ContextForge.git
cd ContextForge
 
# 2. Install dependencies
go mod download
cd frontend && npm install && cd ..
 
# 3. Build for your platform
make mac # macOS arm64 → build/bin/ContextForge.app
make mac-amd64 # macOS Intel
make linux # Linux amd64 → build/bin/ContextForge
make windows # Windows .exe → build/bin/ContextForge.exe
make windows-nsis # Windows .exe + NSIS installer
 
# Or hot-reload dev mode
make dev

🧪 Run tests

make test # all Go tests
make test-race # with race detector
make vet # go vet
