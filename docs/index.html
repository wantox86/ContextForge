Features

Everything you need to brief your AI

No more copy-pasting rules between projects. ContextForge handles it all.

🔍

Auto Stack Detection

Scans your project directory for indicator files and content patterns. Detects Go, Kotlin, Java, Python, Vue, React, Android, Rust, Flutter, and more.

📋

Visual Rule Builder

Browse matched templates, toggle individual rules on/off, and edit content inline. Build exactly the context your AI needs — nothing more.

👁

Live Preview

See the exact Markdown output before writing a single file. Switch between Claude and Copilot targets instantly and compare the results.

⚡

Token Estimator

Estimates token usage per model and warns you before you hit context limits. Supports Claude Sonnet, GitHub Copilot, Cursor, Ollama, and more.

🗃

5 Built-in Templates

Spring Boot + Kotlin, Go + Gin, Python + FastAPI, Vue 3, Android + Kotlin — production-tested rules covering architecture, testing, security, and naming.

💾

Local & Private

Everything runs locally. Your code paths and templates are stored in a local SQLite database. No cloud, no tracking, no account required.

How it works

From project path to AI-ready file in 3 steps

1

Point to your project

Enter your project directory path. ContextForge scans for indicator files (go.mod, pom.xml, package.json, …) and detects your tech stack automatically.

2

Customise your rules

ContextForge loads the best-matching built-in template. Review the rules, toggle any on or off, edit content inline, and add your own custom rules.

3

Export to your AI tool

Choose Claude or GitHub Copilot as the target. Preview the output, check the token estimate, then export directly into your project directory.

Or build from source

# Clone & run
git clone https://github.com/wantox86/ContextForge.git
cd ContextForge
make dev # hot-reload dev mode
 
# Build for your OS
make mac # macOS arm64
make linux # Linux amd64
make windows-nsis # Windows .exe + installer
